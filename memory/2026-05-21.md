## 手机端深度适配（2026-05-21 下午）

### 问题
- 牌桌画布在手机上太大，座位被 `overflow: hidden` 裁切
- 操作面板 sticky 定位挡住座位卡片
- 触摸反馈不明显
- 缺少专门的手机端断点（之前只有 1180px 和 900px）

### 修复

#### 4 级自适应断点
| 断点 | 屏幕 | 布局 |
|---|---|---|
| ≤1180px | 平板/中等 | 单列，牌桌居中相对定位 |
| ≤900px | 平板/小屏 | 座位环→网格 (auto-fit)，操作区不 sticky |
| ≤640px | 手机横屏 | 2 列网格，全宽按钮 |
| ≤480px | 手机竖屏 | 1 列网格，phase-track 隐藏 |

#### 关键改动
- **牌桌中心 (table-center)**：移除 sticky → 改为 `position: relative` 进入文档流，座位在下方显示不遮挡
- **牌桌画布 (table-arena)**：移除 `overflow: hidden` → `overflow: visible`，移除 desktop 的 min-height
- **座位环 (seat-ring)**：desktop 环 `position: absolute + transform` → mobile `position: static + grid`
- **safe-area**：`env(safe-area-inset-*)` 适配刘海屏
- **触摸增强**：`touch-action: manipulation` 禁双击缩放，`-webkit-tap-highlight-color: transparent` 去 iOS 蓝色高亮
- **按钮最小尺寸**：42-44px 触摸区域，action-focus 按钮全宽
- **HTML meta**：`viewport-fit=cover`、`apple-mobile-web-app-capable`、`theme-color`

```text
npm test ✅（3 个测试文件、90 个测试）

```

### 修改文件
- `client/src/styles.css`：~200 行 CSS 增量（4 级断点重写）
- `client/index.html`：手机 meta 标签增强

## 手机端操作可见性修复（2026-05-21 晚间）

### 问题
- 手机端（竖屏和横屏）对局开始后，对局操作完全看不到
- 控件被 `.table-arena` 的 `overflow: hidden` 裁剪
- `.table-control-card`（透明背景）内的控件在移动端不可见

### 修复

#### 所有移动端断点显式设置溢出
- ≤900px：`.in-game-shell .table-arena` 和 `.table-center` 都显式 `overflow: visible`
- ≤640px：同上 + 移除 min-height 约束
- ≤480px：同上

#### 游戏控件卡片加可见边框
- ≤900px/640px/480px：`.table-control-card .subcard` 增加 `border: 1px solid rgba(255,217,142,0.28-0.32)` 和 `background: rgba(13,16,27,0.88)`
- `.action-focus` 边框加粗至 2px

#### 浮动底部操作栏（核心修复）
- ≤640px/480px：`.in-game-shell .table-control-card .action-focus` 改为 `position: fixed; bottom: 0; left: 0; right: 0; z-index: 50`
- 当前待处理操作（宣胜/技能/传递/响应/接收/濒死）始终浮动在屏幕底部
- 圆角顶部 + safe-area-inset-bottom 适配刘海屏
- 最大高度 50-55vh + overflow-y: auto 支持滚动
- 主容器 `.in-game-main` 通过 `:has()` 自动增加底部 padding

#### 状态条竖排
- ≤480px：`status-strip` 改为 `flex-direction: column` 节省横向空间
