# 手机端 UI/排版专项优化记录（2026-05-21）

## 目标

在此前“手机端能看到操作”的基础上，继续优化手机用户体验：降低信息密度、突出当前操作、压缩玩家位、改善日志阅读、兼容小屏和横屏短高度。

## 本轮改动

### 1. 移动端信息层级

- 中央操作卡的头部在手机端 sticky，当前阶段/当前玩家/身份始终更容易看到。
- 系统提示卡片压缩为短文案展示，降低对牌桌区域的占用。
- 非关键说明文本在手机端弱化或隐藏。

### 2. 当前操作浮层优化

- 底部浮动操作卡增加顶部“把手”视觉，用户更容易识别为当前操作区。
- 横屏低高度场景下提高浮层最大高度，避免按钮被挤出屏幕。
- 横屏手机中 label + 控件改为两列；竖屏中恢复单列，减少横向拥挤。

### 3. 玩家位卡片压缩

- ≤640px 隐藏技能长文本和低优先级玩家信息。
- ≤480px 进一步压缩玩家卡、头像、徽章、状态文本。
- ≤390px 小屏专项：头像降至 38×50，座位卡只保留最关键两行信息。

### 4. 日志折叠与精简

- `LogPanel` 改为 `details` 结构。
- 手机端默认展示“重点记录”，完整公屏记录隐藏，减少滚动长度。
- 私人记录仍优先显示，避免错过只对本人可见的信息。

### 5. 横屏专项

- `max-height: 520px and orientation: landscape`：隐藏标题栏，座位使用 4 列紧凑网格。
- 压缩座位高度和头像尺寸，适配手机横屏短高度。
